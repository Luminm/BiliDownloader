BiliTools

本仓库为 BiliTools 仓库的分支版本，基于 Tauri + Vue 3 + Rust 构建，用于哔哩哔哩视频下载与解析。

修复记录：

本分支重点针对下载与队列稳定性做了一系列修复与优化，主要包括：

- 修复大视频合集下载过程中频繁出现的报错
- 优化超过 30 个任务同时下载时的稳定性
- 提升 ffmpeg 处理实例数量，默认按 CPU 线程数计算进程数，可能会导致 CPU 占用偏高
- 添加了通过主页链接批量下载作者主页的功能

具体修复：

- SQLite 写入串行化（单连接 + 加长 busy_timeout），避免数据库并发写冲突；aria2 RPC 超时与连接错误纳入自动重试范围
- 修复队列渲染异常、调度器暂停/恢复失效，以及 aria2 暂停 GID 用错（误用 task.id，应使用 subtask.id）的问题
- 恢复调度器启动/暂停控件：dispatch 时正确进入 Running 状态；暂停/恢复会遍历队列并下发给各任务
- 前端请求错误正确向上传递；缺失 DASH 音频时自动回退
- 整体提升错误容忍度与下载重试稳定性
- 修复唯一输出路径，并恢复构建与配置文件
- 修复删除已完成记录时持续报错：删除改为只清理记录，不再走取消下载的流程；已完成的记录改为临时记录，仅保留在本次运行中，不再写入数据库
- 重复的取消请求按已处理对待，不再产生 “Scheduler not found” 报错
- 修复 aria2c 报 “GID ... is not found”：GID 已不存在不再重试四次，暂停/恢复对它视为无事可做；被取消的任务不再上报中途失败
- 错误提示一次只显示一个，删除失败或批量操作时不再堆满窗口
